# StiebelISG

IP-Symcon-Bibliothek für das STIEBEL ELTRON Internet Service Gateway (ISG).

## Module

* [StiebelISG](StiebelISG/README.md): Liest Prozessdaten und Status des ISG aus und schaltet Einstellungen und Zeitprogramme.

## Installation

Im Module Store nach „StiebelISG“ suchen oder im Module Control diese URL hinzufügen: `https://github.com/ggerrd/StiebelISG`

Dieses Modul ist kein Produkt der STIEBEL ELTRON GmbH & Co. KG und wird von ihr nicht unterstützt.
